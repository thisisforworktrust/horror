# Night Shift: Corridor 13

A browser-playable 3D horror mini-game built with Three.js.

## Play locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Controls

- **WASD**: move
- **Mouse**: look around
- **Shift**: sprint
- **Esc**: pause/unlock mouse

## Objective

Collect all 3 glowing totems while staying sane, then run to the red-lit exit before the stalker reaches you.
